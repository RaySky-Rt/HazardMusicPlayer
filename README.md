# HazardMusicPlayer

面向低版本低配置安卓设备的轻量第三方网易云音乐客户端

## 功能

- 首页每日推荐、搜索、推荐歌单
- 同步红心歌单/创建的歌单/收藏的歌单/收藏的专辑
- 在线播放 最高支持48kHz Flac
- 下载歌曲到本地离线播放
- 本地播放历史

## 最低运行配置

- 至少30MB可用储存空间
- 至少10MB可用RAM
- 安卓6.0及以上
